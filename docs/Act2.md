地点：**Tokyo**（Kiro's Place、Daiki Tower、Emi Massage、Business Tower、Gun Shop、Clothing Shop），**Chicago**（Hotel、Safehouse 等）。

| Mission | 做法 |

### Broken Pieces（打碎 10 个花瓶）
1. **Daiki Tower**：进楼，左边。
2. **Daiki Tower**：走到吧台下面的楼梯处往右，箱子上。
3. Tokyo **Gun Shop**：左边，两块招牌之间那个人旁边。
4. **Emi Massage**：从正门进，右边桌上。
5. **Emi Massage**：正门进，往前左转，进 "Baths" 房间，在另一个插花的花瓶旁边。
6. **Emi Massage**：正门进，往前右转，远处的门旁边。
7. **Business Tower**：用 keycard 坐电梯上去后，进右边房间，房间右侧。
8. **Business Tower**：电梯上去后一直走到玻璃门，进玻璃门，弹药箱上。
9. **Business Tower**：走到玻璃门后进左边电梯，右手边。
10. Chicago **Hotel**：上楼，左边第一个房间，抽屉柜上。

> 7–9 在 Business Tower 主线里，进去时顺手打掉。

### Authentic Set（6 幅画，都在 Tokyo）
1. **Kiro's Place**：进公寓，地上，木板旁。
2. **Daiki Tower**：进楼走到吧台，酒保身后。
3. **Daiki Tower**：走到吧台下面的楼梯处，左边。
4. **Emi Massage**：从垃圾桶旁的门进去往右，中间那面墙上。
5. **Emi Massage**：接着进右边第二个房间（1 张床、2 幅画），要的是床正上方那幅**鸟**。
6. **Business Tower**：电梯上去后一直走到玻璃房间，左边。

## Cheats
Wiki 列出的 Act 2 代码是 `revive` `perso` `reload`。**【代码】** 实际游戏脚本里 Act 2 没有 `reload`，代码表和 Act 1 一样，另外还多了几条：

| Code | 效果（按脚本推断，未逐个实测） |
|---|---|
| `revive` / `money` / `treasure` / `perso` / `halloween` / `burst` / `snipe` | 同 Act 1 |
| `watchout` | 换上 16 号武器（应为 Act 2 新增的 Crossbow） |
| `animal` | 切到 Kiro 并换上一套特殊服装 |
| `mafioso` | 切到 Vinnie + 特殊服装 + Thompson + $10000 |
| `blackmamba` | 切到 Shorty + 特殊服装 + Kunai + $10000 |
| `finishhim` | 切到 Kiro + 特殊服装 + 一把投掷武器 + $10000 |
| `yuuma` | 直接跳到第 310 关，似乎是最终战 Yuuma（慎用，可能打乱进度） |
